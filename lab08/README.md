### Пуассоновский поток. События на сервере
Моделирование потока заявок на сервер.

**Задание:**
- событие — поступление заявки;
- определить число заявок за интервал времени T;
- построить распределение числа заявок;
- вычислить среднее и дисперсию;
- сделать вывод.

**Короткий отчёт:**
Реализована веб-симуляция пуассоновского потока заявок на сервер.
Интервалы между событиями генерируются по экспоненциальному закону, далее считается число заявок в каждом интервале T, строится распределение, вычисляются среднее и дисперсия.
На основе сравнения с теоретическим значением μ = λT формируется вывод о согласованности результатов с моделью Пуассона.
