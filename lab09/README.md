# Лабораторная работа №9: Система массового обслуживания с отказами (без очереди)

## Теоретические сведения

В данной лабораторной работе исследуется простейшая система массового обслуживания (СМО) с отказами. В системе присутствует один канал обслуживания, а очередь для ожидания не предусмотрена (система типа M/M/1/0 или M/M/1 с отказами).

### Основные характеристики и параметры системы:
- **$\lambda$ (интенсивность поступления заявок)** — среднее число заявок, поступающих в систему за единицу времени. Поток заявок считается пуассоновским, поэтому интервалы между поступлениями распределены по экспоненциальному закону с параметром $\lambda$.
- **$\mu$ (интенсивность обслуживания)** — среднее число заявок, которое канал способен обслужить за единицу времени. Время обслуживания распределено по экспоненциальному закону с параметром $\mu$.
- **$\rho$ (нагрузка / приведенная интенсивность)** — вычисляется как отношение интенсивностей: $\rho = \frac{\lambda}{\mu}$.

Поскольку система не имеет очереди, любая заявка, поступившая в момент, когда канал обслуживания занят, немедленно получает **отказ** и покидает систему необслуженной. Таким образом, система может находиться только в двух состояниях:
- $S_0$ — канал свободен (система простаивает).
- $S_1$ — канал занят (система обслуживает заявку).

### Теоретические формулы

1. **Вероятность простоя системы, $P_0$**:
   Доля времени, в течение которого система готова принять новую заявку. Также является вероятностью того, что система в случайный момент времени находится в состоянии $S_0$.
   $$P_0 = \frac{1}{1 + \rho} = \frac{\mu}{\lambda + \mu}$$

2. **Вероятность отказа (канал занят), $P_1$**:
   Вероятность того, что новая заявка застанет систему в состоянии $S_1$ и будет отклонена.
   $$P_1 = \frac{\rho}{1 + \rho} = \frac{\lambda}{\lambda + \mu}$$

3. **Относительная пропускная способность, $Q$**:
   Доля успешно принятых (и обслуженных) заявок от их общего числа. Для системы без очереди она равна вероятности того, что система при поступлении заявки свободна.
   $$Q = 1 - P_1 = P_0$$

4. **Абсолютная пропускная способность, $A$**:
   Среднее число заявок, успешно обслуживаемых системой в единицу времени.
   $$A = \lambda \cdot Q$$

### Моделирование

В рамках лабораторной работы реализуется событийно-ориентированная симуляция работы данной СМО:
- Генерируются экспоненциально распределенные времена прихода заявок на основе интенсивности $\lambda$.
- Если в момент прихода канал свободен, генерируется время обслуживания (по экспоненциальному закону с параметром $\mu$), и канал переходит в состояние 1.
- Если канал занят, заявка учитывается как отклонённая («отказ»).
- По мере выполнения симуляции вычисляются эмпирические вероятности состояний и пропускная способность для оценки их сходимости к теоретическим значениям по мере роста времени симуляции (T).
